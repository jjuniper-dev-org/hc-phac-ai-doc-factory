# HC/PHAC AI Document Factory

This repository is the working source-control and orchestration space for large AI-assisted documents, including:

- AI Playbook
- Data Architecture Plan
- Enterprise Data and AI Platform material
- Architecture and governance briefing products

## Operating model

- GitHub is the working source-control and orchestration layer.
- GitHub Issues define work packages.
- Pull Requests preserve review history.
- Bots may draft and review, but do not merge to main.
- OneDrive is used for rendered draft exchange.
- SACR remains the repository of record for stable drafts and final approved documents.

## Content rule

Do not commit Protected B, sensitive security details, credentials, Cabinet confidence, or controlled records unless the repository and workflow are formally approved for that classification.

## Human approval rule

Bots propose. Humans approve. SACR receives stable drafts.
