# Context Pack — AI Playbook

## Purpose

This context pack provides controlled context for agents drafting or reviewing the HC/PHAC AI Playbook.

## Mission context

HC/PHAC needs a practical AI Playbook to move from fragmented experimentation toward governed, auditable, reusable, and responsible AI adoption.

The playbook should help programs, DTB, OCDO, EA, TPO, ARB, and executive stakeholders understand:

- how AI ideas enter the system
- how use cases are assessed
- how risk and readiness are determined
- how platform routing works
- when PATH, HAIL, Purview, Secure Gateway, Power Platform, Copilot, CANChat, or GCTranslate are relevant
- what governance gates apply
- what evidence is required
- how AI moves from idea to production safely

## Core architecture position

Use this as working EA framing unless superseded:

> HAIL runs workloads. PATH governs AI execution. Purview governs data. Secure Gateway governs external access. Power Platform and Copilot Studio provide low-code, workflow, and agent interaction surfaces. GREP demonstrates decision assurance. PMRA validates regulatory-science platform demand.

## Required distinctions

Agents must distinguish between:

1. Approved GC / HC / PHAC policy or strategy
2. EA/TPO working interpretation
3. Recommended architecture position
4. Open decision requiring governance
5. Example or illustrative pattern

## Core topics

The AI Playbook should cover:

- AI intake
- Use case inventory
- AI risk tiering
- AIA / PIA / SA&A triggers
- ADM / DM accountability
- Human-in-the-loop controls
- Responsible AI
- Data readiness
- Platform routing
- Pattern library
- Review gates
- AI operations
- Monitoring and continuous improvement

## Do not do

Agents must not:

- claim a working EA position is formally approved
- invent a governance body or approval
- treat CANChat or Copilot as substitutes for Protected B AI workloads
- treat HAIL as a complete enterprise AI platform by itself
- treat PATH as a runtime replacement for HAIL
- treat Purview as an AI runtime
- include Protected B or sensitive content
