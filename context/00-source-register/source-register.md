## Source classification

| Level | Meaning |
|---|---|
| Authoritative | Approved GC / HC / PHAC source or formal strategy |
| Working interpretation | EA/TPO/OCDO working analysis, not yet formally approved |
| Meeting intelligence | Notes or synthesis from conversations; must be validated |
| External reference | External source requiring citation and currency check |
| Excluded | Not to be used by bots |
