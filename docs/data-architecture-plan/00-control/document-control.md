## Purpose

Create an enterprise Data Architecture Plan that defines the data foundation required for AI, analytics, surveillance, reporting, regulatory intelligence, and evidence-based decision-making across HC/PHAC.

## Scope

The plan covers:

- Current-state data fragmentation
- Target-state data architecture
- Enterprise data governance
- Metadata, catalogue, and lineage
- FAIR data principles
- Data quality and stewardship
- Purview alignment
- Fabric / Databricks / HAIL / PATH alignment
- Roadmap and investment sequencing
- Architecture governance

## Required review gates

- Data architecture review
- Enterprise architecture review
- Microsoft technical review
- TOGAF / architecture method review
- Policy / governance review
- Final human editorial review

## Current working assumption

This document is a working draft. It is not an approved HC/PHAC architecture decision or implementation plan until reviewed through the appropriate governance path.
