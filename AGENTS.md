# Agent Control File

## Purpose

This file tells drafting and review agents how to work in this repository.

## Core rules

1. Do not invent policy, decisions, approvals, or official positions.
2. Distinguish between approved source material, working EA interpretation, open decisions, and recommendations.
3. Work section-by-section.
4. Use Pull Requests for all changes.
5. Do not push directly to main.
6. Flag evidence gaps.
7. Preserve public-sector tone.
8. Write for CIO, ADM, CDO, ARB, TPO, DTB, and OCDO audiences.
9. Keep drafts suitable for later Word/SACR finalization.
10. Do not include protected or sensitive information unless explicitly cleared.

## Required review agents

Each major document should pass through:

- Writing review
- Enterprise architecture review
- Data architecture review
- Microsoft technical review
- TOGAF / architecture method review
- Policy and governance review
- Accessibility / plain language review
- Citation and evidence review

## Merge rule

Only James or an explicitly delegated human reviewer should approve merge to main.
