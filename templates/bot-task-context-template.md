# Bot Task Context Template

Use this template when assigning work to a bot.

## Task

Describe the specific task.

## Document

Name the target document.

## Section

Name the section.

## Context pack

Reference the relevant context pack.

Example:

- context/01-context-packs/ai-playbook-context-pack.md

## Source register

Reference the source register.

Example:

- context/00-source-register/source-register.md

## Decision records

Reference relevant decision records.

Example:

- context/02-decision-records/DR-0001-document-factory-model.md

## Required output

Specify the artifact the bot should produce.

Examples:

- Draft section
- Review comments
- Gap analysis
- Revised section
- Table
- Decision summary

## Constraints

List constraints.

Examples:

- Do not invent policy.
- Mark EA interpretation clearly.
- Do not include Protected B or sensitive information.
- Use executive-ready language.
- Flag evidence gaps.

## Acceptance criteria

List what must be true for the task to be accepted.
